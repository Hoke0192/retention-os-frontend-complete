# 留才 RetentionOS · 完整前端版

组织离职风险分析与留任行动系统的完整前端实现，包含七个正式业务模块：决策总览、数据工坊、组织洞察、复核工作台、行动中心、管理报告和模型说明。

## 在线体验

https://hoke0192.github.io/retention-os-frontend-complete/

## 线上能力

- 完整导航、组织下钻与角色权限视图
- CSV 数据接入、字段校验、质量阻断与风险更新
- 组织风险分布、主要驱动、趋势和行动影响推演
- 个体案例复核、理由记录与行动流转
- 行动创建、任务进度、状态管理和结果记录
- AI 摘要人工确认与 PDF 管理报告导出
- 浏览器内状态保存，刷新页面后可继续体验

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

GitHub Pages 从 `main` 分支的 `/docs` 目录提供静态站点。更新线上版本时，重新执行 `npm run build`，并同步 `dist/` 内容至 `docs/` 后提交即可。

## 数据与安全

系统内置脱敏合成数据，不包含真实员工信息、密钥、口令或访问令牌。该仓库是静态前端体验版本；完整全栈系统应连接独立后端与事务数据库。
